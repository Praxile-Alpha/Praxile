# Seeded DOCX development execution, 2026-10-20

This is one development repair task, three candidate comparisons and six fresh
container executions. It is not six independent tasks, an official JobBench run,
or held-out evidence. No candidate is promoted.

The [machine-readable receipt](docx-six-arm-20261020.json) records frozen inputs,
artifact and source-record hashes, runtime status, independent checks and usage.
It is a local observation, not third-party attestation. Raw trajectories and DOCX
outputs remain local; hashes alone do not make this bundle fully reproducible.
No credentials, private rubric or document bodies are published here.

## Protocol

The [previously generated candidates](docx-typed-actions-20261019/README.md) were
frozen before these runs. Each candidate got a fresh baseline followed by its own
candidate arm, using the same five-page seed, immutable container image, wheel,
offline pypdf dependency, public instruction and 12-step/600-second budget.
Execution used MiniMax-M3.1-Flash with explicit reasoning_effort=low. Candidate
context activation and injection are recorded separately from permission and
promotion. Baselines had no candidate context. No earlier arm output was supplied
as context to later arms. Each pair manifest was frozen before its execution;
this was not a prospectively registered statistical study.

The local wheel included existing user README edits: source commit identity is
not a claim that the entire build tree was pristine. Runtime model output still
uses the normal validated action protocol; candidate action examples were not
executed directly. Transport retry defaults were not changed.

Independent pre/post rendering counted pages; a checksum comparison checked that
the notification memo was unchanged. These checks do NOT establish semantic
preservation, readability or official task success. No official judge ran.

not a general lifecycle reliability claim.

independent judging costs are excluded; monetary cost remains unknown. First and
second candidates used fewer execution tokens, but this does not demonstrate a
net efficiency gain at equal quality. Composition used more tokens than its failed
baseline; failed arms are retained rather than removed from the comparison.

## Quality boundary and next work

A post-hoc text inspection raised potential omissions of source compliance items
in the first and second candidate outputs (artist consents and youth background
checks). This was not a frozen semantic evaluator, and keyword absence alone is
not proof of omission. Treat it as a review signal, not an official score. Agent
claims of preserved content are not accepted as verifier outcomes.

Next: independent source-to-output content review with evidence references,
behavior comparison, and broader frozen task-level evaluation. The R2/R3 quality,
transfer and full-cost requirements remain incomplete. These six runs establish
real execution of all three drafts, not that the drafts are useful experiences.
